# DDSP-Violin MIDI

Audio examples of the MIDI-controllable violin synthesiser built on
[DDSP-Violin](https://github.com/JoaoerDuarte/DDSP-Violin-EUSIPCO2026) (in preparation).

A physically-informed DDSP synthesiser driven by pitch and loudness curves, with the harmonic
source constrained by bowed-string acoustics (brightness, bow position, residuals) and a learned
body filter, trained on recorded violin performances (MOSA, 15 violinists).

## Audio examples

Listen at [joaoerduarte.github.io/DDSP-Violin-MIDI](https://joaoerduarte.github.io/DDSP-Violin-MIDI/)
(the page is `index.html`, the files are in `audio_examples/`).
